# Как подключить Figma MCP в следующий раз

Эта инструкция нужна, чтобы Codex мог читать открытый файл Figma через локальный сервер `Figma Desktop Bridge`.

## 1. Запусти локальный MCP-сервер

Открой терминал и запусти сервер, который был настроен для `figma-console-mcp`.

Если сервер уже запущен, этот шаг можно пропустить.

## 2. Открой нужный файл в Figma Desktop

Важно: нужен именно Figma Desktop, не браузерная версия.

Открой файл:

```text
Portfolio 2026
```

## 3. Запусти плагин в Figma

В Figma открой:

```text
Plugins -> Development -> Figma Desktop Bridge
```

Не выбирай раздел `Widgets`.

Если плагин нужно импортировать заново:

```text
Plugins -> Development -> Import plugin from manifest
```

И выбери файл:

```text
C:\Users\user\.figma-console-mcp\plugin\manifest.json
```

После запуска плагина оставь его окно открытым.

## 4. Проверь статус

В окне плагина должен появиться статус вроде:

```text
Local ready
Connected
```

Если появилась красная ошибка, нужно прислать скриншот ошибки в чат.

## 5. Что написать Codex в новом чате

Напиши:

```text
Проверь подключение к Figma через локальный figma-console MCP.
Файл должен быть Portfolio 2026.
Дальше работаем через этот сервер.
```

После этого Codex должен проверить подключение через `figma-console`, увидеть файл `Portfolio 2026` и сможет читать фреймы напрямую из Figma.

## Важно

- Окно плагина `Figma Desktop Bridge` должно оставаться открытым.
- Если Figma закрывалась, плагин нужно запустить заново.
- Если Codex не видит сервер, перезапусти локальный MCP-сервер и снова открой плагин в Figma.
- Для работы лучше присылать ссылку на конкретный фрейм или название блока.
